# Безопасность

Tervix находится в preview. Гарантированный срок поддержки и стабильная ветка
security updates пока не установлены. Используйте последнюю проверенную сборку.

## Сообщение об уязвимости

Не публикуйте ключи, токены, env контейнеров, терминальную историю или полный
Docker inspect в открытых issues. Если на GitHub доступен **Security → Report a
vulnerability**, используйте приватный отчёт. Если функция недоступна, создайте
issue без деталей эксплуатации с просьбой организовать приватный канал.

Укажите commit/версию, ОС, компонент, минимальное безопасное воспроизведение и
влияние. Не отправляйте реальные credentials или конфигурацию чужих систем.

## Границы доверия

- Docker Engine обладает высокими привилегиями; подключайтесь только к доверенным
  endpoints. Удаление контейнера не удаляет volumes автоматически.
- SSH использует системный OpenSSH и его host verification; приложение не
  должно отключать проверки ключей хоста.
- OSC 52 и автоматическое открытие терминальных ссылок отключены.
- Не запускайте приложение с повышенными правами без необходимости.
- Диагностика и логи могут содержать чувствительные данные — проверяйте их перед
  публикацией. Отчёт о зависимостях не заменяет vulnerability/license audit.
